# Acceptance Criteria

## Dashboard

- [ ] Dashboard shows daily learning streak (consecutive days with at least 1 review session).
- [ ] Dashboard shows number of cards due for review today.
- [ ] Dashboard shows total number of decks.
- [ ] Dashboard shows overall mastery percentage (cards with interval > 21 days / total cards).
- [ ] Dashboard shows skill radar chart (Listening, Speaking, Reading, Writing).
- [ ] Dashboard has a "Start Review" quick-action button.
- [ ] Dashboard updates after completing a review session.

## Create Deck

- [ ] User can create a new deck with a title (required) and description (optional).
- [ ] New deck appears in the deck list immediately after creation.
- [ ] System shows error when title is empty.
- [ ] System shows error when title exceeds 200 characters.
- [ ] Deck title is trimmed of leading/trailing whitespace before saving.

## Deck List

- [ ] Deck list shows all user's decks.
- [ ] Each deck card shows: title, card count, mastery %.
- [ ] User can filter decks: All / Due for review / Mastered.
- [ ] Decks are sorted by most recently active first.
- [ ] "Create new deck" button is visible and accessible.

## Add Card

- [ ] User can add a card with word (required) and meaning (required).
- [ ] User can optionally add example sentence.
- [ ] New card appears in the deck immediately after saving.
- [ ] Deck card count increases by 1.
- [ ] System shows error when word is empty.
- [ ] System shows error when meaning is empty.
- [ ] System shows error when a card with the same word already exists in the same deck (duplicate blocked).

## Review Session

- [ ] Session loads cards due for review (nextReviewAt <= now, or never reviewed), sorted by priority.
- [ ] Flashcard shows word on front side.
- [ ] Tapping the card flips it to reveal meaning and example.
- [ ] User can rate: Again, Hard, Good, Easy.
- [ ] "Again" marks the card as wrong (wrongCount++) and resets its interval to 1 day for next session.
- [ ] "Hard" reduces interval by 20% (interval * 0.8).
- [ ] "Good" increases interval per SM-2: if interval <= 1 day -> 3 days; if interval <= 6 days -> 7 days; else interval * easeFactor.
- [ ] "Easy" increases interval with bonus: interval * easeFactor * 1.3.
- [ ] Progress bar shows cards remaining in session (current / total).
- [ ] When all due cards are reviewed, session ends automatically.
- [ ] Session summary shows: total cards reviewed, accuracy (% rated Good/Easy), time spent.
- [ ] Session creates a ReviewSession record in Supabase with duration and hourOfDay.

## Spaced Repetition

- [ ] New cards (never reviewed) have interval = 1 day and easeFactor = 2.5.
- [ ] With default easeFactor (2.5), good progression follows: 1d -> 3d -> 7d -> 18d -> 45d.
- [ ] "Again" resets interval to 1 day and reduces easeFactor by 0.2 (min 1.3).
- [ ] "Hard" reduces easeFactor by 0.15 (min 1.3) and interval by 20%.
- [ ] "Good" keeps easeFactor unchanged.
- [ ] "Easy" increases easeFactor by 0.15.
- [ ] Cards with interval > 21 days are marked as "Mastered".
- [ ] EaseFactor never drops below 1.3.
- [ ] System correctly calculates nextReviewAt = now + intervalDays.

## Deck Statistics

- [ ] Deck detail shows total cards count.
- [ ] Deck detail shows mastered cards count (interval > 21 days).
- [ ] Deck detail shows learning cards count (has ReviewLog, interval <= 21 days).
- [ ] Deck detail shows new (unseen) cards count (no ReviewLog entry).
- [ ] Deck detail shows accuracy percentage (cards rated Good or Easy / total reviews).

## PDF Import

- [ ] User can upload a PDF file for vocabulary extraction.
- [ ] System shows preview of extracted cards before confirming import.
- [ ] User can edit extracted cards (word, meaning) before importing.
- [ ] Imported cards are saved into a new deck with isAutoGenerated = true.
- [ ] System handles unreadable PDFs with an error message.
- [ ] System handles PDFs with no extractable vocabulary with a warning message.

## Deck Management

- [ ] User can edit deck title and description.
- [ ] User can delete a deck with a confirmation dialog.
- [ ] Deleting a deck removes all its cards and associated ReviewLogs.
- [ ] User can delete individual cards from a deck.
- [ ] Deleting a card removes its associated ReviewLog.

## Persistence

- [ ] All deck and card data is saved to Supabase.
- [ ] Review history and SRS data (ReviewLog) persist across sessions.
- [ ] UserStats streak data persists and syncs on app load.

## UI

- [ ] UI follows the visual style from DESIGN.md.
- [ ] UI is mobile-first and responsive (works at 320px+).
- [ ] Flashcard flip animation is smooth (< 300ms).
- [ ] Review session is usable with one hand on mobile.
- [ ] Buttons and touch targets are at least 44px.
- [ ] Loading states are shown while fetching data from Supabase.
- [ ] Empty states are shown when lists have no data.
