# Entity Model

> Field names below use English conventions. The SQL column names from beepoly.sql are shown in parentheses where they differ.

## Entity: Deck (bo_the_tu_vung)

Represents a vocabulary deck (a collection of flashcards).

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| id | id | BIGINT | yes | Primary key, auto-increment |
| userId | nguoi_dung_id | BIGINT | yes | Owner of the deck |
| title | tieu_de | VARCHAR(200) | yes | Deck title |
| description | mo_ta | TEXT | no | Optional description |
| sourcePdfUrl | source_pdf_url | VARCHAR(500) | no | PDF source if imported |
| isAutoGenerated | is_auto_generated | BOOLEAN | yes | True if created by PDF import, default false |
| createdAt | ngay_tao | TIMESTAMPTZ | yes | Creation date, default now() |

## Entity: Card (the_tu_vung)

Represents a single vocabulary flashcard.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| id | id | BIGINT | yes | Primary key, auto-increment |
| deckId | bo_the_id | BIGINT | yes | Parent deck reference |
| word | tu | VARCHAR(150) | yes | English word |
| meaning | nghia | TEXT | yes | Vietnamese meaning |
| example | vi_du | TEXT | no | Example sentence |
| audioUrl | duong_dan_am_thanh | VARCHAR(500) | no | Pronunciation audio URL |

## Entity: ReviewLog (lich_su_on_the)

Tracks spaced repetition data for each card per user. Maps to SM-2 algorithm state.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| userId | nguoi_dung_id | BIGINT | yes | The learner (part of composite PK) |
| cardId | flashcard_id | BIGINT | yes | The flashcard (part of composite PK) |
| easeFactor | he_so_do_de | NUMERIC(3,2) | yes | SM-2 ease factor, default 2.5 |
| intervalDays | khoang_cach_ngay | INTEGER | yes | Days until next review, default 1 |
| nextReviewAt | lan_on_tiep_theo | TIMESTAMPTZ | yes | Scheduled next review date |
| wrongCount | so_lan_sai | INTEGER | yes | Times rated "Again", default 0 |

Primary Key: (userId, cardId)

## Entity: ReviewSession (phien_hoc)

Records a study session. Used for streak tracking and session summaries.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| id | id | BIGINT | yes | Primary key, auto-increment |
| userId | nguoi_dung_id | BIGINT | yes | The learner |
| startedAt | bat_dau_luc | TIMESTAMPTZ | yes | Session start time |
| endedAt | ket_thuc_luc | TIMESTAMPTZ | no | Session end time |
| durationSeconds | duration_sec | INTEGER | no | Total session duration in seconds |
| hourOfDay | gio_trong_ngay | SMALLINT | no | Hour of day (0-23), for analytics |

## Entity: UserStats (thong_ke_nguoi_dung)

Aggregated learning statistics per user. One row per user.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| userId | nguoi_dung_id | BIGINT | yes | Primary key, the learner |
| totalExperience | tong_kinh_nghiem | BIGINT | yes | XP earned, default 0 |
| currentStreak | chuoi_hoc_hien_tai | INTEGER | yes | Consecutive days learning, default 0 |
| longestStreak | chuoi_hoc_dai_nhat | INTEGER | yes | Best streak ever, default 0 |
| lastStudyDate | ngay_hoc_cuoi | DATE | no | Date of last study session |

## Entity: DailySkillScore (diem_ky_nang)

Daily snapshot of skill proficiency (populated after exam/questionnaire completion).

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| id | id | BIGINT | yes | Primary key, auto-increment |
| userId | nguoi_dung_id | BIGINT | yes | The learner |
| listening | listening | NUMERIC(5,2) | no | Score 0-100 |
| speaking | speaking | NUMERIC(5,2) | no | Score 0-100 |
| reading | reading | NUMERIC(5,2) | no | Score 0-100 |
| writing | writing | NUMERIC(5,2) | no | Score 0-100 |
| recordedDate | ngay_ghi_nhan | DATE | yes | Date of record |

Unique constraint: (userId, recordedDate)

## Relationships

```
User (nguoi_dung) 1──* Deck (bo_the_tu_vung)
Deck 1──* Card (the_tu_vung)
User 1──* ReviewLog (lich_su_on_the)
Card 1──* ReviewLog
User 1──* ReviewSession (phien_hoc)
User 1──1 UserStats (thong_ke_nguoi_dung)
User 1──* DailySkillScore (diem_ky_nang)
```

## SM-2 Algorithm Constants

| Parameter | Value | Description |
|---|---|---|
| initialInterval | 1 day | First review interval for new cards |
| initialEaseFactor | 2.5 | Starting ease factor (he_so_do_de) |
| minEaseFactor | 1.3 | Minimum ease factor cap |
| intervalEasyBonus | 1.3x | Multiplier for "Easy" rating |
| hardIntervalReduction | 0.8x | Multiplier for "Hard" rating |
| masteredThreshold | 21 days | Interval to consider a card "mastered" |
