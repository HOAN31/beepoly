# Requirements: Flashcard & Vocabulary Learning MVP

## Product Goal

Help English learners build and retain vocabulary through spaced repetition flashcards, with visual progress tracking.

## Target Users

- Individual English learners (all levels A1-C2)
- Students preparing for TOEIC/IELTS who need to expand vocabulary

## Core Features

1. Create and manage vocabulary decks
2. Add vocabulary cards with word, meaning, and example sentence
3. Review cards using spaced repetition algorithm (SM-2 based)
4. Track learning streak and daily progress
5. View vocabulary statistics (mastery %, cards due, accuracy)
6. Import vocabulary from PDF (auto-generate flashcards)

## Out of Scope

- AI conversation / debate mode
- Exam simulation (TOEIC/IELTS mock tests)
- Class management and teacher portal
- Payment and subscription system
- Social features (guilds, leaderboards)
- AR / computer vision features
- Audio playback / pronunciation features
- Parent monitoring view
- CEFR level auto-assignment on cards

## Non-functional Requirements

- App must work on mobile (responsive, mobile-first)
- UI must be intuitive for users aged 12+
- Spaced repetition logic must follow SM-2 algorithm accurately
- Card review should feel smooth with tap gestures
- Session should complete in 5-15 minutes for daily review
