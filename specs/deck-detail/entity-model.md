# Entity Model

## Entity: bo_the_tu_vung (Deck)

Represents a vocabulary deck. Maps to table `bo_the_tu_vung` in beepoly.sql.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| id | id | BIGINT | yes | Primary key, auto-increment |
| userId | nguoi_dung_id | BIGINT | yes | Owner of the deck |
| title | tieu_de | VARCHAR(200) | no | Deck title |
| sourcePdfUrl | source_pdf_url | VARCHAR(500) | no | PDF source if imported |
| isAutoGenerated | is_auto_generated | BOOLEAN | yes | True if created by PDF import, default false |
| createdAt | ngay_tao | TIMESTAMPTZ | yes | Creation date, default now() |

Note: This table has NO description field.

## Entity: the_tu_vung (Card)

Represents a single vocabulary flashcard inside a deck. Maps to table `the_tu_vung` in beepoly.sql.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| id | id | BIGINT | yes | Primary key, auto-increment |
| deckId | bo_the_id | BIGINT | yes | Parent deck reference |
| word | tu | VARCHAR(150) | yes | English word |
| meaning | nghia | TEXT | no | Vietnamese meaning |
| example | vi_du | TEXT | no | Example sentence |
| audioUrl | duong_dan_am_thanh | VARCHAR(500) | no | Pronunciation audio URL |

Note: This table has NO status column — status is derived (see below).

## Entity: lich_su_on_the (ReviewLog)

Tracks spaced repetition data per card per user. Maps to table `lich_su_on_the` in beepoly.sql.

| Field | SQL Column | Type | Required | Description |
|---|---|---|---|---|
| userId | nguoi_dung_id | BIGINT | yes | The learner (part of composite PK) |
| cardId | flashcard_id | BIGINT | yes | The flashcard (part of composite PK) |
| easeFactor | he_so_do_de | NUMERIC(3,2) | yes | SM-2 ease factor, default 2.5 |
| intervalDays | khoang_cach_ngay | INTEGER | yes | Days until next review, default 1 |
| nextReviewAt | lan_on_tiep_theo | TIMESTAMPTZ | no | Scheduled next review date |
| wrongCount | so_lan_sai | INTEGER | yes | Times rated "Again", default 0 |

Primary Key: (nguoi_dung_id, flashcard_id)

## Card Status Derivation

Card status is NOT stored in the database. It is derived from `lich_su_on_the`:

| Status | Condition |
|---|---|
| new | No row in `lich_su_on_the` for `(nguoi_dung_id, flashcard_id)` |
| learning | Row exists AND `khoang_cach_ngay <= 21` |
| mastered | Row exists AND `khoang_cach_ngay > 21` |

## Deck Statistics (derived)

| Statistic | How calculated |
|---|---|
| total | Count of `the_tu_vung` where `bo_the_id` = deck.id |
| mastered | Count of cards where status = mastered |
| learning | Count of cards where status = learning |
| new | Count of cards where status = new |
| accuracy | (cards with `so_lan_sai = 0` / cards with review history) * 100%; 0% if no review history |

Invariant: mastered + learning + new = total

## Data Storage

- Database: PostgreSQL (Supabase)
- Tables: `bo_the_tu_vung`, `the_tu_vung`, `lich_su_on_the`
