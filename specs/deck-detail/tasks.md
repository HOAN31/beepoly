- Review Session route is reachable and shows only the placeholder content.

## Task 3: Build Breadcrumb + DeckHeader

- Breadcrumb: `Decks` (link to `/decks`) / deck title (plain text, truncate on narrow widths)
- Header shows title (`tieu_de`) and `Created` (`ngay_tao`) — and nothing else
- Render `Untitled deck` when title is null (header + breadcrumb)
- Actions: Back, Edit, Delete, + Add card, Start Review
- `Start Review` is the primary (blue) button

Acceptance check:
- Header shows only title + created date.
- No description, category, or difficulty is rendered.
- All five actions are visible; Start Review is primary.

## Task 7: Add Search + Pagination + EmptyStates

- SearchBar filters by `tu` or `nghia`, client-side; placeholder `Search flashcards…`
- Count label updates (`N cards` / `3 of 12 cards` while searching)
- Pagination: 10 rows/page desktop, 5/page mobile; resets to page 1 when search changes
- Empty deck → `EmptyState` `No flashcards yet` + `+ Add card`
- Zero search results → `EmptyState` `No flashcards match` + `Clear search`

Acceptance check:
- Search filters rows and updates the count label.
- Clearing search restores the full paginated list.
- Both empty states render with the correct actions.
